# Defensive Security Review Checklist

Use only on systems you own or are explicitly authorised to test.

- [ ] Confirm written scope and test window
- [ ] Inventory assets and software versions
- [ ] Review authentication and access controls
- [ ] Check patching and secure configuration
- [ ] Review exposed services and unnecessary ports
- [ ] Record findings with severity and evidence
- [ ] Apply approved remediation
- [ ] Re-test and document closure
- [ ] Remove temporary test data and access
